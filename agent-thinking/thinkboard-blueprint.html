01

The pipeline & the guardrail

plan §1–§2

The differentiator isn't the seven stages — it's the scope anchor. Every session is pinned to an initial question, and every new turn is checked against it before the pipeline trusts the input.

OCR/highlight weighting runs client-side only: the browser's Selection/Range API for text-layer PDFs, Tesseract.js (WASM) for scanned pages. Handwriting is Tesseract's weak spot — budget a manual-correction fallback rather than trusting OCR confidence there.

Feature spec

plan §3
Access & LLM routing
No API exists to check whether an arbitrary email holds a ChatGPT Plus subscription — that's account-only. Replaced with bring-your-own-key: a user's own key is tried first, then falls back to a shared, rate-limited pool.§3.1 · resolved server-side, only by the gateway
Artifact sheet
shadcn Sheet, up to two artifacts side by side — "Main Thinking" + a PDF note. Highlighting inside either fires a scoped mini-summarization call on just that span, not the whole document.§3.2 · one-off, not a full pipeline rerun
Memory separation
Four stores, not one buffer — persona (cross-session voice), group (optional, team-shared), conversation (hard-capped, older turns summarized into scoped research), and initial (split into ideas vs limitations).§3.3
Internet / material ratio
A RAG weighting slider, default 20% live web search / 80% uploaded-material vector store, merged before the Research stage. Adjustable per session.§3.4
Three modes
Planned — the structured pipeline view. Descriptive — same conclusions in prose, sources and bias spelled out. Visualize — diagram syntax (Mermaid for pipeline-emitted diagrams, React Flow for hand-edited ones) — not generated images.§3.5 · tldraw rejected (paid license to remove watermark)

Budget Medium at minimum, likely Large once the gateway's own pool is layered on top of client traffic. Use the transaction-mode pooler (port 6543) for serverless / high-connection-count paths.

OCR accuracy on scanned/handwritten material may need a manual-correction step before it's trustworthy.

BYO-key adoption is unproven — if most of the 450 users lean on the shared pool, the cost model changes significantly.
